## 🖋 此情可待 · 中国伤感诗词

纯黑白水墨风格，WebGL 实时流体背景，横向翻页杂志排版。

### 🎨 技术栈
- **引擎**: guizang 电子墨水 (WebGL + Motion One)
- **背景**: 双 WebGL Shader（全息色散 / 旋转涡流），鼠标交互
- **排版**: Playfair Display + Noto Serif SC 杂志级字体栈
- **动效**: Motion One stagger 入场动画
- **音乐**: 黑胶唱片 CSS 播放器 + 云端古琴音乐
- **水墨人物**: 6 幅 SVG 手绘（孤舟蓑笠翁 / 墨竹 / 仕女 / 枯枝寒梅 / 幽兰 / 书生 / 孤松）
