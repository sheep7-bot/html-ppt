S19 · 06 / 08
FOUR KEY LESSONS

四年教会我的四件事

01
基础决定上限
数据结构、操作系统、网络——这些"无用"的基础课，最终决定了能走多远。
02
动手是最好的学习
书读百遍不如自己写一遍。15 个项目，每一个都比上一堂课的收获大。
03
社区的力量
开源、技术社团、黑客松——和优秀的人一起做有意义的事。
04
拥抱 AI 工具
Claude Code / Copilot 不是替代程序员，而是放大每一个开发者的能力。
