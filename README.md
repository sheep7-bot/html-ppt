## ✨ 特点

- 🖥️ **纯 HTML** — 无需 PowerPoint，浏览器直接打开
- 📱 **响应式** — 支持手机、平板、电脑
- ⌨️ **键盘导航** — 方向键 / 空格翻页
- 🌐 **在线可访问** — 通过 GitHub Pages 托管

## 🚀 如何运行

```bash
# 克隆仓库
git clone https://github.com/sheep7-bot/html-ppt.git

# 直接打开任意 index.html 即可浏览
# 或使用本地服务器
cd html-ppt
python -m http.server 8080
# 访问 http://localhost:8080
```
